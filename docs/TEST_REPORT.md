Production smoke использует собственный вымышленный набор, затем удаляет только его; согласие возвращается к исходному состоянию. Реальный дневник не очищался. Production-деплой c5fdec1 подтвердил доставку CA и ключей в Functions; TLS verification включён. Первый запрос Max завершился provider timeout (20 секунд), следующая полная проверка прошла. Сетевые ошибки не трактуются как успешный AI, невалидные цитаты не сохраняются.

## Реальная оценка модели

`scripts/evaluate-ai.ts` выполняется вручную, не в CI. На GigaChat-2-Max проверены восемь вымышленных случаев: пять кратких разных записей, два опоздания, два описания одного события, отрицательные наблюдения/извинение/догадка о мотиве, противоречие с prompt injection, два разных набора ответов B, все пропуски B. Все восемь прошли схему/источники; смысл просмотрен отдельно. Разные ответы B дали разные рекомендации; один эпизод не стал pattern, краткие записи не превратились в черту личности, фиктивный позитив/оценка совместимости не появились. Последнее усиление запрета UUID в тексте проверено повторным B.

Это ограниченная оценка, не гарантия истинности будущих выводов. Проверка точной цитаты не доказывает корректность интерпретации. Повторение консервативно требует разные даты событий; истории в один день остаются наблюдениями. Сложные response_format-схемы воспроизводимо вызывали TimeoutError и не используются для отчётов/вопросов; простой структурированный tags-вызов прошёл.

## Оставшиеся ручные проверки

Домашний и мобильный интернет РФ без VPN: открытие URL, сохранение и чтение после перезагрузки, Сигналы при пяти записях. На телефоне проверить клавиатуру и сохранение файла экспорта. Полная приёмка остаётся открытой до этих проверок.

## Исправление после обратной связи владельца
На c5fdec1 владелец получил timeout, затем неподтверждённый источник; прежний успешный smoke не доказал стабильности всех запросов. Новый реестр коротких ссылок и общий бюджет прошли typecheck/lint/build и 22 теста, включая чужие источники, самостоятельную цитату и изоляцию deadline. Проверка нового production-деплоя ожидается.

2 октября: первая production-проверка 61b06ea прошла Сигналы и A/пропуски, но дописка оборвана платформой ровно на 30 000 мс. Набор удалён. Добавлен потоковый транспорт ожидания; повторная production-проверка обязательна.

2 октября: 59212f2 опубликован в Netlify и успешно собран GitHub Pages. Новые Сигналы, A/пропуски и A-дописка с источником прошли фоновый production API. Во время B корректно сработал stale при конкурентном изменении; повторная проверка продолжается. Владелец после перезагрузки подтвердил: анализ отобразился корректно. Подтверждение не содержит сведений о двух разных сетях.

Дополнительная диагностика: пропуски title и summary воспроизведены в логах. Тест сложной response_format-схемы отвергнут: модель вставляла посторонние токены вне JSON-полей, даже с finish_reason=stop. Эксперимент не публиковался. Итоговый адаптер сохраняет строгие смысловые проверки, дополняет только представление и допускает до 5000 токенов. Реальные вымышленные A-дописка, B-three-hours и B-spontaneous прошли. Диагностические сырые ответы сохраняются только явным ручным скриптом на вымышленных данных в ignored artifacts; production не записывает их.
