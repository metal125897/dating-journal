# Продукт и требования

Личный русскоязычный дневник знакомств помогает помнить записанный опыт, различать наблюдения и гипотезы, сопоставлять контекст со своими ценностями. Это одна общая рабочая область без входа. Бюджет 0 ₽; целевой доступ — РФ без VPN. Полное ТЗ: `references/AGENT_TASK.md`.

## Первый релиз

Люди: создание по одному имени/псевдониму; необязательные дата рождения, город, сфера, контекст, отдельные списки любит/не любит. Возраст по календарю, будущая дата запрещена. Архив сохраняет историю; возврат восстанавливает активность; удаление каскадное.

Журнал: человек, свободный текст, дата события. CRUD, поиск по полному тексту, фильтры активных/по человеку/архива и тегов. Пять тегов: контакт, напряжение, поступок, договорённость, рефлексия. AI-разметка не блокирует сохранение; ручные правки важнее ответа модели.

Обзор: активные люди, записи последних семи календарных дней только активных, последние события и быстрые действия. Дата последней записи — нейтральная справка, отсутствие записи не означает отсутствие общения.

Настройки: о себе и ценности, реальное серверное AI-согласие, полный JSON-экспорт, удаление всех данных с подтверждением, отдельное обозначенное демо. Рабочая база стартует пустой.

Сигналы: явная генерация при пяти записях; подтверждённые повторения, неоднозначные наблюдения, подтверждённые положительные моменты, состав основания без процентов и резюме. Ссылки открывают источники. Результат сохраняется и устаревает при изменениях; удалённые источники не остаются в цитатах.

Вопросы A: ровно три вопроса, локальные черновики, пакет ответов с `-`, атомарная запись сводки и дополнений. Все `-` — без AI. Отправленные ответы неизменяемы, исправления отдельными дописками. Пропущенные темы не переспрашиваются.

Вопросы B: свободный вопрос → три уточнения → пакет ответов/`-` → развёрнутый ответ с источниками, использованием ответов и одним наблюдаемым шагом. Сессии и результаты сохраняются.

Идеи: только сообщение о будущем генераторе, без формы и AI-запросов, без порога пяти записей.

## За границами

Нет фото, сравнений и рейтингов людей, диагнозов, процентов совместимости, соцфункций, внешней аналитики, стриков, тревожных напоминаний, платежей, обучения на правках, PWA/offline и автоматических AI-комментариев. Макет содержит имитации, они годятся только для подписанного демо.
