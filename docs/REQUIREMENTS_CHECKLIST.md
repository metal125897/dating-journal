# Приёмка R01–R22

Дата обновления: 2 октября 2026. Проверки относятся только к дневнику. «Реализовано» не заменяет полную приёмку на реальном телефоне и двух сетях РФ.

| Критерий | Фактическое состояние |
|---|---|
| R01 Отдельный проект, макет | Пройдено: отдельный каталог/репозиторий, вишлист не менялся |
| R02 Mobile/desktop | Проверены 390×844, 360 px, 1440×900; реальная клавиатура телефона ещё не проверена |
| R03 Постоянные данные | Production CRUD, reload и чтение в другой вкладке проверены |
| R04 Человек по имени | Проверено в UI: обязательно только имя |
| R05 Записи, теги, поиск | CRUD, ручной тег, полный поиск и reload проверены |
| R06 Архив/возврат | Проверено в изолированном демо |
| R07 Порог пять | Доменные тесты и production API: четыре записи отклонены |
| R08 Персональный AI и источники | Новые Сигналы прошли production smoke и подтверждены владельцем; точные цитаты разрешаются сервером |
| R09 Без ярлыков/ложного позитива | Промпт/валидация и восемь вымышленных модельных случаев проверены; это ограниченная оценка |
| R10 Устаревание/удаление цитат | Доменные тесты и production отклонение конкурентной правки; переход и подсветка источника проверены в UI |
| R11 A три вопроса/пакет | Production: три вопроса, атомарный пакет пропусков, дописка с неизменным исходным пакетом |
| R12 B уточнения/ответ | Production 28655a5: три уточнения, финал учитывает текущие ответы, проверены источник пакета и следующий шаг |
| R13 Пропуски | A без модели; B на трёх вымышленных наборах, пропуски не становятся фактами |
| R14 Черновики/ответы в БД | UI черновик после reload, production пакет/дописка; demo/live разделены |
| R15 Идеи-заглушка | Проверена при нуле записей, модель не вызывается |
| R16 Согласие/независимый CRUD | Серверные проверки согласия пройдены; ошибки AI не перезаписывают записи |
| R17 Экспорт/wipe/демо | Полный JSON и вариант копирования проверены; каскад/wipe в доменных тестах; production wipe реальных данных не выполнялся |
| R18 Повторы/ошибки | Production CRUD UUID и Neon jobs: один worker, подмена fingerprint отклонена, ошибка/явный повтор проверены |
| R19 Секреты/бесплатные планы | Server-only ключи, Free инфраструктура, сканирование перед каждым push; новые оплаты не подключались |
| R20 Проверки сборки | Typecheck/lint/build и 26 тестов; GitHub Actions успешно публикует |
| R21 Настоящие БД и AI | Neon, GigaChat-2-Max и production background worker проверены |
| R22 Публикация и РФ | Публичный URL проверен; владелец подтвердил исправленные Сигналы. Отдельное подтверждение домашней и мобильной сети без VPN остаётся открытым |
