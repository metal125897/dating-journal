# Дизайн по макету

Основной референс — `references/index2.html`. Сохранить его спокойный тёмный язык, карточки, градиенты, ленту и собственные меню. Не переносить декоративную рамку телефона.

Инициалы вместо фото. Шрифты/иконки локальные; SVG для основных действий. Предпочтения различаются цветом и текстовой подписью. Временная лента с фиолетовыми точками и датами. FAB 59px, нижняя навигация с четырьмя пунктами, карточки действий и sheet с тонкими границами.

390×844 — основной мобильный экран, также 360/430/768 и 1440×900. На ПК ограниченная ширина, удобная боковая навигация; карточки не растягиваются на весь экран. Safe-area, 100dvh, прокручиваемые формы и меню, дополнительный отступ под FAB. Поля минимум 16px, основные touch targets 44×44. Нет горизонтального скролла; длинные слова переносятся.

Фокус видим, диалоги удерживают фокус и закрываются Escape. Клавиатурная навигация, доступные названия SVG, reduced-motion. Шапка/выбор человека/AI-вкладки не перемещаются при переключении вкладок. Никаких процентов совместимости, тревожных счётчиков или неработающих переключателей.

3 октября: только русские крупные заголовки, без английских повторов. Мини-карточки людей 86 px, две строки с многоточием, без профессии. Поиск: SVG в центре по высоте, padding-left 46 px. html scrollbar-gutter:stable; desktop-nav и бренд совпадают по X, FAB вне основной колонки. Обзор — две строки «На этой неделе» и число записей.
