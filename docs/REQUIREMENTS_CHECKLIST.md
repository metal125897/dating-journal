# Приёмка R01–R22

Дата: 1 октября 2026. «Реализовано» не заменяет проверку. Полная приёмка остаётся открытой до облачных, модельных и сетевых проверок.

| Критерий | Фактическое состояние |
|---|---|
| R01 Отдельный проект, макет | Пройдено: отдельный каталог/репозиторий, сборка, CSS исходного макета |
| R02 Mobile/desktop | Не проверено полностью: визуальная проверка в процессе |
| R03 Постоянные данные | Облачный CRUD проверен; смена браузера/production ещё не проверены |
| R04 Человек по имени | Реализовано; формы требуют только имя |
| R05 Записи, теги, поиск | Реализовано; серверный CRUD и ручные теги проверены, UI-проверки в процессе |
| R06 Архив/возврат | Реализовано; полная UI-проверка ещё не выполнена |
| R07 Порог пять | Пройдено: доменные тесты 4/5, удаление пятой, прямой API 403 при четырёх |
| R08 Персональный AI и источники | Настоящие сигналы и проверка цитат пройдены на вымышленном наборе |
| R09 Без ярлыков/ложного позитива | Валидация и промпт реализованы; полный набор модельных оценок ещё не выполнен |
| R10 Устаревание/удаление цитат | Доменные тесты пройдены; полная UI-проверка в процессе |
| R11 A три вопроса/пакет | Реализовано, облачная проверка в процессе |
| R12 B уточнения/ответ | Реализовано, облачная проверка ещё не выполнена |
| R13 Пропуски | Доменные тесты пройдены; модельное соблюдение границ ещё оценивается |
| R14 Черновики/ответы в БД | Реализовано; E2E ещё не завершён |
| R15 Идеи-заглушка | Реализовано без вызова модели |
| R16 Согласие/независимый CRUD | Доменные тесты пройдены; отказ AI не меняет исходный снимок |
| R17 Экспорт/wipe/демо | Доменные тесты каскада и wipe пройдены; разрушительный production-тест не выполняется |
| R18 Повторы/ошибки | Облачная идемпотентность пройдена, таймаут БД 10 секунд; E2E ошибок в процессе |
| R19 Секреты/бесплатные планы | Серверная изоляция реализована, локальный env исключён; проверка перед push обязательна |
| R20 Проверки сборки | Пройдено: typecheck, lint, 13 тестов, build |
| R21 Настоящие БД и AI | Пройдено локальным API: облачный CRUD/чтение, реальные теги и Сигналы |
| R22 Публикация и РФ | Не проверено: публичный URL/API ещё настраиваются, две сети РФ требуют проверки |
