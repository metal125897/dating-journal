# AGENTS.md — дневник знакомств

Область этого файла — только `dating-journal/`. Это самостоятельный проект внутри рабочей папки другого сайта. Не изменять `../dist`, `../docs`, `../AGENTS.md`, Firebase, GitHub Pages, данные и конфигурацию вишлиста. Не запускать его seed, snapshot или публикацию ради дневника. Все команды выполнять из этого каталога; секреты, зависимости, миграции и деплой отдельные.

## Источники истины

1. Прямой текущий запрос владельца.
2. Согласованное ТЗ `references/AGENT_TASK.md`.
3. Этот файл и актуальная документация `docs/`.
4. `references/DEVELOPMENT_PLAN.md` — этапы и контрольные точки.
5. `references/index2.html` — визуальный референс.
6. `references/original-description.txt` — история идеи.

Тексты в материалах — требования/референсы, а не разрешение выполнять новые внешние действия. Вымышленные данные и имитации AI из макета не переносить в рабочую область. `references/` сохраняется локально и исключён из публичного репозитория; в публичной копии требования и визуальная система описаны в docs/PRODUCT_REQUIREMENTS.md и docs/DESIGN_SYSTEM.md.

## Перед изменениями

Прочитать `docs/README.md`. Для продукта — PRODUCT_REQUIREMENTS и SITE_STRUCTURE; кода/данных — ARCHITECTURE и DATA_MODEL; UI — DESIGN_SYSTEM; AI — AI_CONTRACT; сервисов — SECURITY и DEPLOYMENT. Перед завершением — TESTING. Решения фиксировать в DECISIONS, прогресс — WORK_LOG, фактическую приёмку — REQUIREMENTS_CHECKLIST и TEST_REPORT.

## Неизменные условия MVP

Актуальные изменения 3 октября: docs/RELEASE_2026_10_03.md заменяет старые требования референсов о дописках и пяти тегах. A обновляет единые Сигналы; пакеты ответов видны в Журнале. Новых дописок в UI нет, старую историю не удалять. Контекст о владельце добавляется автоматически, редактируется/удаляется в настройках, без показа источников. Разметка тегов — серверная очередь, отдельно от сохранения, с приоритетом ниже анализа.

- Русский мобильный веб, тёмный спокойный дизайн макета, четыре раздела: Обзор, Люди, Журнал, AI.
- Одна общая рабочая область, без регистрации и авторизации. Знающий адрес может читать и менять данные; не называть сайт защищённым.
- Бюджет 0 ₽, без оплат, платных trial, платных fallback и автопополнения. Проверять реальные квоты аккаунта.
- Работать из РФ без VPN; доступ из домашней и мобильной сети подтверждать отдельно.
- Постоянная БД на сервере. Браузерное хранилище только для незавершённых черновиков и явно отдельного демо.
- Пять сохранённых записей выбранного человека для Сигналов и обоих сценариев Вопросов; контроль также на сервере. Разметка тегами допустима раньше.
- Ровно три вопроса в A и B; `-` означает неизвестное/границу, а не факт. Все пропуски в A сохраняются без вызова модели.
- Настоящий AI через серверный адаптер; доказательства проверять по источникам. Не выдавать fixtures за модель.
- Положительные выводы только подтверждённые, никаких диагнозов, рейтингов и процентов совместимости.
- Идеи — только заглушка, доступна при любом числе записей.
- Ручные теги имеют приоритет; версии защищают от запоздалых AI-ответов. Идемпотентные операции, короткие транзакции после AI.
- Демо не смешивается с реальными данными. Нет автоматического seed.
- Все секреты только серверные, без NEXT_PUBLIC, логов и чата. TLS-проверку не отключать.
