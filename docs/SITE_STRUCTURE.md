# Структура сайта

Корень открывает Обзор. Маркетингового лендинга нет. Маршрут хранится в URL через параметры `view`, `person`, `entry`, `tab`; браузерные назад/вперёд, прямые ссылки и перезагрузка сохраняют экран. Основные разделы — Обзор, Люди, Журнал, AI.

| Экран | Содержание и переходы |
|---|---|
| Обзор | Неделя активных людей, последние записи, добавить человека/запись, настройки, персональный AI |
| Люди | Поиск, активные, архив; профиль по нажатию карточки |
| Профиль | Имя/инициал, известные поля, контекст, предпочтения, архив/возврат, редактирование, журнал, AI, каскадное удаление |
| Журнал | Все активные / по человеку / архив; теги, полный поиск, временная лента |
| Запись | Полный текст, дата, профиль, текущие теги, редактирование/удаление |
| Форма записи | Собственный выбор человека, текст и дата; восстановление черновика, сохранение только после ответа сервера |
| AI | Постоянные шапка, выбор человека и вкладки; Сигналы / Вопросы / Идеи |
| Сигналы | Порог N/5, явная генерация, сохранённый отчёт, источники, дата и устаревание |
| Вопросы | A «Вопросы тебе» и B свободный вопрос, по три поля и сохранённые результаты |
| Идеи | Сообщение «Идеи подарков и свиданий появятся позже» |
| Настройки | О себе, ценности, согласие AI, экспорт, удаление, демо |

Формы человека и управление тегами — диалоги/bottom sheet. На телефоне нижняя навигация и FAB; FAB скрывается в формах. Меню прокручиваются, показывают счётчики. Все экраны имеют loading/empty/error/content; действия busy/success/recoverable error. Ошибки не очищают текст и не включают демо автоматически.

Экспорт: подготовка свежего полного снимка → ссылка «Скачать JSON»; если браузер не поддерживает загрузку, доступен JSON для копирования. Подготовленный файл сбрасывается при изменении ревизии/режима. Источники переходят к записи с выделенной цитатой, сохранённому контексту, конкретному ответу или дописке; история браузера сохраняется.

3 октября: новые настройки ожиданий и AI-контекста; маршрут answers открывает конкретный пакет из Журнала и подсвечивает источник ответа. Вопросы A показывают ответы и кнопку «Открыть Сигналы». Форма новой дописки и отдельный отчёт A удалены. B остаётся отдельным разбором. Документированные изменения: RELEASE_2026_10_03.md.
