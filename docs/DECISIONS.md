# Журнал решений

## 2026-10-01

- D01: самостоятельный каталог `dating-journal/`; родительский вишлист неизменен. Все исходные референсы скопированы внутрь, проект переносим.
- D02: React/TypeScript/Vite, нативный CSS по макету; PostgreSQL/Neon, отдельный серверный адаптер GigaChat. Стек из ТЗ, окончательное подтверждение требует облачного стенда.
- D03: одна рабочая область без входа согласно ТЗ. Не добавлять существующую Firebase-авторизацию вишлиста.
- D04: агрегат JSONB с общей ревизией и отдельными записями SQL DATE. Короткая compare-and-swap транзакция для личного объёма; отсутствие ORM/отдельной очереди.
- D05: операции AI с БД-lease, безопасными ошибками и неизменяемым снимком; провайдер не вызывается внутри SQL-транзакции.
- D06: GitHub Pages/Netlify Free/Neon Free/GigaChat Freemium — проверяемые кандидаты. Владелец вошёл в Neon, Sber Studio и Netlify; локальные серверные ключи заполнены. Neon миграция и настоящий вызов GigaChat прошли. Публикация ещё настраивается.
- D07: демо явное и изолированное; в рабочем режиме нет seed или имитации AI.

- D08: владелец сообщил о блокировке Vercel и попросил GitHub Pages. Клиент переведён на Vite/React/TypeScript с относительным base; API вынесен в Netlify Functions. Это прямое изменение исходного кандидата стека. Секреты и БД на Pages не размещаются. Netlify Free — hard cap без автоматического списания; доступ из РФ проверяется отдельно.


- D09: после модельных проверок аналитика переведена на GigaChat-2-Max в существующей бесплатной Freemium-квоте. Платные пакеты и fallback не включены. Штатная простая JSON-схема используется только для тегов; сложные схемы отчёта/вопросов превышали timeout и не внедрены. Все ответы проверяются локальными Zod-схемами и источниками. Повтор требует разные даты события: два наблюдения в один день консервативно показываются как наблюдения, пока отдельные эпизоды нельзя достоверно различить.

## D10 — реестр цитат и общий бюджет AI
После сообщения владельца о TimeoutError и неподтверждённом источнике модель переведена на выбор готовых фрагментов по короткому ref. Самостоятельное копирование UUID/quote исключено; строгая проверка исходных источников сохранена. Это проверяет происхождение цитаты, но не истинность интерпретации. Генерация до 35 секунд, общий бюджет 55 секунд с резервом фиксации 12 секунд. TLS включён.
